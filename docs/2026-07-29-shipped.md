## Major features

### Quick Stop — same-day "add me to your route" booking
A separate, faster booking path that runs alongside normal instant booking, with
its own daily limit and rules (bypasses minimum-value / soonest-booking). Full
lifecycle: customer request → AI qualification → contractor offer → payment →
arrival verification → completion / cancellation / no-show.
- `b8844b2` M1 — schema, config lib, Settings section
- `69b2e07` M2 — AI qualification with a deterministic safety screener (fails closed)
- `4741b51` M3 — customer request path in `/book`
- `a5faccc` M4 — contractor request queue, offer flow, route math
- `ebf2859` M5 — payment link, app-side 15-min expiry, webhook confirmation
- `2a2e926` M6 — arrival verification, tiered cancellation refunds, no-show reporting
- `ede28b7` Phase-1 hardening — tests + 3 real fixes from review (refund-tier order, `.or()` injection, late-payment refund race)
- `fa9f723` Phase 2 — editable refund tiers, revised-window negotiation, on-site diagnostic conversion

### Internal staff admin console (`/admin`)
First cross-account operator surface. `ADMIN_EMAILS` allowlist + `requireAdmin()`
404-gate, its own chrome, and an `admin_actions` audit trail on every mutating action.
- `7a07309` — Overview, Accounts (support view: profile, Connect/payout, fee tier, feature flags, activity), Quick Stops governance (event timeline, manual refund, resolve/adjudicate), Money oversight (fees, refunds, disputes, payout health), Audit log. Plus account governance: credits ledger, Quick Stop no-show lock, suspend/unsuspend (enforced in `requireOwnerContext`), JSON export, confirm-gated delete.
- `9a768f5` — show the owner's real business name (site `company_name`) instead of the `My Business` placeholder across the console.
- Needs a prod SQL migration (`admin_actions`, `account_credits`, `accounts.suspended_*` / `extra_stop_locked_*`) + the `ADMIN_EMAILS` Vercel env var.
