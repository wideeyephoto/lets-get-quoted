# Purpose
Open self-service booking slots, buffer times, and appointment availability on your website.

# Steps
## Set up booking windows and technician availability
1. Go to Website Builder → Online Booking.
2. Configure bookable time windows (e.g. 8:00 AM–11:00 AM, 1:00 PM–4:00 PM).
3. Set booking buffer times (e.g. minimum 4-hour advance notice).
4. Specify which services allow direct booking versus estimate consultation requests.

## Prevent overbooking
The booking engine automatically checks technician calendars and suppresses slots when capacity is full.



# Done State
Homeowners will book consultations and repair visits directly into your open schedule windows.

# Common Failure
**Customers cannot see available slots for tomorrow.**
Check your minimum advance notice buffer in booking settings.
