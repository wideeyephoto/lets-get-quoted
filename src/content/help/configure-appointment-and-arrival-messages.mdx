# Purpose
Automate 24-hour appointment reminders, morning-of confirmation texts, and technician arrival ETAs.

# Steps
## Set reminder delivery cadences
1. Enable 24-hour reminder texts: Sends an automated confirmation SMS the day before scheduled work.
2. Enable 2-hour reminder texts: Reminds the client to clear work areas and secure pets.
3. Configure the technician "On My Way" button template.

## Customize reminder copy
Insert dynamic tags like {customer_name}, {technician_name}, {arrival_window}, and {company_phone} into your templates.



# Done State
You will virtually eliminate customer no-shows and prepare homeowners for crew arrivals.

# Common Failure
**Customer texted back to reschedule after a reminder.**
Customer replies appear immediately in your Messages inbox for fast office rescheduling.
