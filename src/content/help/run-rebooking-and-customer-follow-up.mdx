# Purpose
Re-engage past clients with automated seasonal maintenance reminders and tune-up offers.

# Steps
## Configure automated rebooking intervals
1. Select trade triggers: e.g. 6-month HVAC filter/tune-up, 12-month plumbing inspection, or annual gutter cleaning.
2. Set automated SMS/email invitations linking to your online booking page.
3. Include promotional seasonal discounts if desired.

## Review rebooking conversion metrics
Track rebooking campaign response rates and revenue generated from past customers in your dashboard reports.



# Done State
You will generate steady repeat work from your existing customer database during slow seasons.

# Common Failure
**A rebooking text sent to an inactive customer.**
Archive inactive client records to exclude them from automated rebooking triggers.
