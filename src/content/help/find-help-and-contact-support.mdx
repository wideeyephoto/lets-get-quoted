# Purpose
Search user guides, diagnose common issues with troubleshooting tools, and open support tickets.

# Steps
## Search documentation and interactive troubleshooting
1. Use the Manual Explorer (/help/manual) to search by task, keyword, or error message.
2. Use the in-app Troubleshooter in the Help Center to diagnose quote delivery, Stripe payout, or SMS issues.

## Submit a support case with evidence
If an issue requires support intervention, open a ticket from /dashboard/help. Include the affected record URL, timestamp, steps taken, and screenshots for rapid resolution.



# Done State
You will resolve technical questions quickly with fast self-service guides and responsive support.

# Common Failure
**Urgent payment or chargeback issue.**
Email support@letsgetquoted.com with your business name, affected invoice ID, and dispute evidence.
