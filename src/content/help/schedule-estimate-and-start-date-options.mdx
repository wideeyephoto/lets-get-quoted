# Purpose
Book on-site consultations, reserve project start windows, and coordinate estimator calendars.

# Steps
## Book an on-site consultation
1. From the lead details, click "Book Visit".
2. Choose an available date and arrival window that aligns with your schedule.
3. Assign an estimator or field technician to the visit.
4. Confirm to automatically send the customer an SMS confirmation with their arrival window.

## Hold a tentative start date on quotes
When assembling a quote, you can specify a proposed start date or timeline window. This date is held provisionally until the customer approves the estimate.



# Done State
Estimate visits and tentative project starts will be booked without schedule conflicts.

# Common Failure
**Customer wants to reschedule an estimate visit.**
Open Schedule, find the visit card, click Reschedule, and select a new time slot.
